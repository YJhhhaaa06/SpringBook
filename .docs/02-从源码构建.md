# 02 从源码构建

目标：把源码编译成可运行的 jar，或在本机改代码调试。

## 前置条件

| 组件 | 要求 |
|---|---|
| JDK | 21 或更高 |
| Maven | **不用单独安装**，仓库自带 `mvnw` / `mvnw.cmd` |
| MySQL | 8.0 或更高（推荐 8.4） |
| 网络 | 首次构建需要下载依赖，约 200 MB |

> 构建**不会**改变数据库驱动版本。`mysql-connector-j` 由 Spring Boot 的依赖管理锁定，重新构建后仍是同一个版本，所以 MySQL 8.0+ 的要求不会因为"自己编译一遍"而消失。

## 第一步：确认 JDK

```bash
java -version
```

没有 `javac` 或版本低于 21 时，设一下 `JAVA_HOME`：

**Windows（PowerShell）**

```powershell
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-21.0.x-hotspot"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
```

**Linux / macOS**

```bash
export JAVA_HOME=/path/to/jdk-21
export PATH="$JAVA_HOME/bin:$PATH"
```

## 第二步：构建

在项目根目录（能看到 `pom.xml` 的那一层）执行。

**Windows**

```powershell
.\mvnw.cmd -DskipTests package
```

**Linux / macOS**

```bash
./mvnw -DskipTests package
```

首次执行要下载 Maven 本体和全部依赖，几分钟到十几分钟都有可能，取决于网络。看到 `BUILD SUCCESS` 即可。

产物：

```
target/SpringBook-0.0.1-SNAPSHOT.jar
```

## 第三步：运行

```bash
java -jar target/SpringBook-0.0.1-SNAPSHOT.jar
```

默认连 `localhost:3307` 的 `springbook` 库。本机数据库端口或账号不同时，用环境变量覆盖，不必改代码：

**Windows（PowerShell）**

```powershell
$env:DB_HOST = "127.0.0.1"
$env:DB_PORT = "3306"
$env:DB_USER = "root"
$env:DB_PASSWORD = "你的密码"
java -jar target/SpringBook-0.0.1-SNAPSHOT.jar
```

**Linux / macOS**

```bash
DB_HOST=127.0.0.1 DB_PORT=3306 DB_USER=root DB_PASSWORD=你的密码 \
  java -jar target/SpringBook-0.0.1-SNAPSHOT.jar
```

启动后打开 <http://localhost:8080/>。

## 改代码后怎么生效

本项目没有引入热部署，改完需要重新构建：

```bash
./mvnw -DskipTests package && java -jar target/SpringBook-0.0.1-SNAPSHOT.jar
```

开发时更顺手的方式是让 Maven 直接跑：

```bash
./mvnw spring-boot:run
```

前端是 `src/main/resources/static/` 下的静态文件，会被打进 jar。改完前端同样要重新构建，或者直接刷新页面（`spring-boot:run` 下静态资源会重新读取）。

## 跑测试

```bash
./mvnw test
```

集成测试用 Testcontainers 临时拉一个 MySQL 容器，所以**本机必须有可用的 Docker**，否则测试会失败（这是环境问题，不是代码问题）。

只想跳过测试快速打包，前面已经加了 `-DskipTests`。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| `JAVA_HOME not found` | JDK 没装或没设 `JAVA_HOME`。装 JDK 21，设好后**新开一个终端**再试 |
| `UnsupportedClassVersionError` | 用低于 21 的 JDK 运行。换 JDK 21+，或用 `./mvnw -version` 确认 Maven 用的是哪个 JDK |
| 依赖下载很慢或超时 | 网络问题。可换国内镜像：在 `~/.m2/settings.xml` 的 `<mirrors>` 里加阿里云仓库 |
| `Tests run: ... Failures: 1` 且报连接容器失败 | Docker 没启动。启动 Docker Desktop 后重试，或加 `-DskipTests` 先打包 |
| 构建成功但启动报 `Unknown database` | 数据库不存在且连接串没带 `createDatabaseIfNotExist=true`。手工建库或补上该参数 |

更多启动期报错见 [05 排错](05-排错.md)。
