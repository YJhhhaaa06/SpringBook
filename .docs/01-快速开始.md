# 01 快速开始：用 jar 跑起来

目标：不改一行代码，十分钟内看到系统跑起来。

## 你需要准备

| 组件 | 版本 | 检查命令 |
|---|---|---|
| JDK | 21 或更高 | `java -version` |
| MySQL | 8.0 或更高（推荐 8.4） | 见下方"确认数据库" |

`java -version` 输出里出现 `21`、`22`、`23`、`24`、`25` 都可以。出现 `1.8`、`11`、`17` 就不行。

## 第一步：拿到程序

解压后目录应当是这样，下面这些文件要放在同一层：

```
SpringBook/
├── SpringBook.jar          程序本体
├── 启动.bat                Windows 双击运行
├── 启动.sh                 Linux / macOS 运行
├── application.properties  唯一需要修改的配置
└── README.md
```

## 第二步：确认数据库

有 MySQL 8.0+ 就跳到第三步，执行一条命令确认版本：

```sql
SELECT VERSION();
```

返回 `8.0.x` 或 `8.4.x` 才可以用。如果是 `5.7.x`，或者你装的是 MariaDB，请看本节末尾。

### 没有 MySQL 的两种情况

**情况 A：用 Docker 起一个（推荐，不污染本机）**

```bash
docker run -d --name springbook-mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=root \
  -e MYSQL_DATABASE=springbook \
  -e TZ=Asia/Shanghai \
  mysql:8.4
```

等十几秒，容器状态变成 `healthy` 即可。如果 3306 已被占用，把 `-p 3306:3306` 改成 `-p 3307:3306`，第三步的端口也相应改成 3307。

**情况 B：本机安装 MySQL 8.4**

到 <https://dev.mysql.com/downloads/mysql/> 下载 8.4 的安装包，装完后启动服务。安装时设置的 root 口令要记住，第三步要用。

**只有 MySQL 5.7 怎么办**：不要试图改驱动，装一个 8.4 与它共存，把 8.4 的端口设成 3307，第三步填 3307 即可。原因见 [05 排错](05-排错.md#mysql-57-或-mariadb)。

## 第三步：改三行配置

用记事本打开 `application.properties`，只改这三处：

```properties
# 1) 数据库地址：端口默认 3306，库名不用改
spring.datasource.url=jdbc:mysql://127.0.0.1:3306/springbook?characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true&createDatabaseIfNotExist=true

# 2) 账号
spring.datasource.username=root

# 3) 密码：改成你自己的
spring.datasource.password=改成你的密码
```

> 库不需要提前建。连接串里的 `createDatabaseIfNotExist=true` 会让驱动自动创建 `springbook` 库，字符集正好是 `utf8mb4`。

## 第四步：启动

**Windows**：双击 `启动.bat`。

**Linux / macOS**：

```bash
sh 启动.sh
```

窗口里出现类似下面这行就说明启动成功（秒数会因机器而异）：

```
Started SpringBookApplication in 4.1 seconds
```

首次启动会执行数据库迁移并灌入演示数据，多花两三秒是正常的。

> 双击后窗口一闪就没：说明 Java 没找到。脚本会打印 `[ERROR] Java not found`，装好 JDK 21 后重新打开命令行再试。详见 [05 排错](05-排错.md#java-not-found)。

## 第五步：打开页面

浏览器访问 <http://localhost:8080/>。

用管理员登录：

| 账号 | 口令 |
|---|---|
| `admin` | `admin123` |

也可以用读者账号体验借阅视角，例如 `及时雨` / `123456`。

## 怎么确认一切正常

```bash
curl http://localhost:8080/actuator/health
```

返回 `{"status":"UP"}` 即可。页面能打开但接口报错的情况基本不存在，因为前端资源就在这个 jar 里。

## 停止

- 双击启动的：关掉命令行窗口，或按 `Ctrl + C`。
- Docker 起的数据库：`docker stop springbook-mysql`，下次 `docker start springbook-mysql`。

## 换端口

8080 被占用时，改 `application.properties` 最后一行：

```properties
server.port=8081
```

然后访问 <http://localhost:8081/>。
