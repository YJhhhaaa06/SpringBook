# 图书信息管理系统 — 接口文档（第二版）

> 依据：`.docs/技术选型.md` §5 接口清单 + 范围评审补充（图书修改 PUT、删除预约保护）+ `.docs/第二版实施方案.md`（罚款闭环、借阅上限、数据归属、自助注册、入库/下架、读者管理）。
> 所有接口均为 JSON REST；成功 `code=0`，业务失败返回对应错误码与 HTTP 状态。

## 0. 通用约定

### 基础地址与鉴权

| 项 | 值 |
|---|---|
| Base URL | `http://localhost:8080`（`server.port` 可覆盖） |
| 认证方式 | `Authorization: Bearer <JWT>`（HS256，有效期 2 小时） |
| 匿名接口 | `POST /api/auth/login`、`POST /api/auth/register`、`GET /actuator/health` |
| 管理动作（需 ADMIN） | 图书新增/修改/删除/入库下架、读者新增/列表/资料修改/冻结解冻、缴纳罚款 |
| 其余 `/api/**` | 需已认证；**READER 仅能操作自身资源**（数据归属校验，越权返回 `40300`，ADMIN 可代办） |

### 统一响应

```json
{ "code": 0, "message": "ok", "data": { } }
```

- `code = 0` 成功；非 0 见文末错误码表。
- 参数校验失败返回 `40001`，`data` 为 `{字段名: 提示}` 的明细 Map。
- 金额口径：**存储与出入参均含 `*Cents`（分，整数）**；`price`/`fine`/`unpaidFine` 字段为换算后的元（BigDecimal），仅用于展示，勿用于计算。

### 时间口径

- 借期默认 30 天（`book.loan.days`），应还时间 `dueAt` 在借出时刻确定，落库不重算。
- 「是否逾期」实时派生：`status=BORROWED && dueAt < now`，不落库。
- 罚款：逾期天数（不足一天计一天，向上取整）× 50 分（`book.fine.per-day-cents`），**封顶为该书价格**，归还那一刻结算；罚款状态 `fineStatus`：`NONE`（无罚款）/ `UNPAID`（待缴）/ `PAID`（已缴）。
- **借阅上限**：每人同时在借本数上限 `book.loan.max-borrowing`（默认 5，≤0 视为不限制），借出（含预约履约）时校验。

## 1. 认证

### 1.1 登录

`POST /api/auth/login`（匿名）

```json
{ "username": "admin", "password": "admin123" }
```

响应：

```json
{
  "code": 0, "message": "ok",
  "data": { "token": "eyJhbGciOi...", "expiresInSeconds": 7200 }
}
```

> 冷启动时系统自动创建默认管理员 `admin`（密码取环境变量 `ADMIN_PASSWORD`，缺省 `admin123`），请尽快修改。
> 账号不存在与口令错误统一返回 `40101`，不区分二者。

### 1.2 自助注册（第二版）

`POST /api/auth/register`（匿名）

```json
{ "username": "zhangsan01", "password": "pass-123456", "name": "张三", "phone": "13800001111" }
```

- 同一事务内创建读者资料与 `READER` 账号，**成功直接签发 token**（注册即登录）。
- 用户名重复 → `40915`；手机号重复 → `40904`；密码长度 6-50。
- 注册成功即可用自己的 token 借书/预约（数据归属校验通过）。

### 1.3 修改密码（第二版）

`PUT /api/auth/password`（已认证，修改自己的密码）

```json
{ "oldPassword": "old-pass-123", "newPassword": "new-pass-456" }
```

- 原密码错误 → `40002`；新旧密码相同 → `40001`。
- 无状态 JWT：修改后已签发的旧 token 在过期前仍然有效。

## 2. 图书

### 2.1 新增图书（ADMIN）

`POST /api/books`

```json
{ "isbn": "978-7-111-11111-1", "title": "深入理解计算机系统", "totalCopies": 3, "priceCents": 13900 }
```

- `totalCopies` 为入库总册数；`availableCopies` 初始等于 `totalCopies`。
- 书号重复返回 `40901`。

### 2.2 修改图书（ADMIN）

`PUT /api/books/{id}`

```json
{ "title": "深入理解计算机系统（第3版）", "priceCents": 12900 }
```

- 全量更新书名与价格；总册数调整走 2.3 入库/下架。
- 服务端用 `version` 乐观锁，冲突自动重读重试（最多 3 次），仍失败返回 `40912`。

### 2.3 入库/下架（ADMIN，第二版）

`PATCH /api/books/{id}/copies`

```json
{ "totalCopies": 8 }
```

- 直接给目标总册数；可借数量按差额同步增减。
- 下架保护：新总册数不得低于「在借数 + 未过期 READY 预留数」，否则 `40916`；图书不存在 → `40401`。

### 2.4 删除图书（ADMIN）

`DELETE /api/books/{id}`

- 存在未归还借阅 → `40902`；存在活跃预约（WAITING/READY）→ `40903`；不存在 → `40401`。

### 2.5 查询单本

`GET /api/books/{id}`

```json
{
  "code": 0, "message": "ok",
  "data": {
    "id": 1, "isbn": "978-7-111-11111-1", "title": "深入理解计算机系统",
    "totalCopies": 3, "availableCopies": 2,
    "priceCents": 13900, "price": 139.00,
    "version": 0, "createdAt": "2026-10-19T15:00:00.123", "updatedAt": "2026-10-19T15:00:00.123"
  }
}
```

### 2.6 分页检索

`GET /api/books?keyword=&page=&size=`

- `keyword` 按书名/书号模糊匹配，可省略；`page` 从 1 起，`size` 默认 10、上限 100。
- 响应 `data`：`{ "total": 3, "page": 1, "size": 10, "records": [ ...图书对象... ] }`

### 2.7 查看预约队列

`GET /api/books/{id}/reservations`

- 返回该书全部预约（含历史），按排队时间升序；查询会触发过期 READY 的惰性清理。
- `data` 元素：`{ id, bookId, readerId, readerName, status, createdAt, readyAt, holdUntil }`

## 3. 读者

### 3.1 新增读者（ADMIN）

`POST /api/readers`

```json
{ "name": "张三", "phone": "13800001111" }
```

- 手机号唯一，重复返回 `40904`。

### 3.2 读者列表（ADMIN，第二版）

`GET /api/readers?keyword=&page=&size=`

- `keyword` 按姓名/手机号模糊匹配，可省略；分页口径同图书检索。
- 响应 `data`：`{ "total": 3, "page": 1, "size": 10, "records": [ ...读者对象... ] }`

### 3.3 读者详情（含在借列表与欠款汇总）

`GET /api/readers/{id}`

- **数据归属**：READER 仅能查看自己（查他人 → `40300`），ADMIN 任意。

```json
{
  "code": 0, "message": "ok",
  "data": {
    "id": 1, "name": "张三", "phone": "13800001111", "status": "ACTIVE",
    "createdAt": "2026-10-19T15:00:00.123",
    "unpaidFineCents": 250, "unpaidFine": 2.50,
    "onLoans": [
      { "loanId": 5, "bookId": 2, "bookTitle": "Effective Java",
        "borrowedAt": "2026-10-01T10:00:00", "dueAt": "2026-10-31T10:00:00", "overdue": false }
    ]
  }
}
```

- `unpaidFineCents`/`unpaidFine`：该读者所有待缴罚款汇总（第二版新增）。

### 3.4 修改读者资料（ADMIN，第二版）

`PUT /api/readers/{id}`

```json
{ "name": "张三丰", "phone": "13800002222" }
```

- 手机号与其他读者冲突 → `40904`。

### 3.5 冻结/解冻读者（ADMIN，第二版）

`PUT /api/readers/{id}/status`

```json
{ "status": "FROZEN" }
```

- `status` 仅允许 `ACTIVE` / `FROZEN`（40001 校验失败）。
- 注意：**手动解冻绕不过罚款禁借**——存在 `UNPAID` 罚款的读者即使 `ACTIVE` 仍无法借书/预约。

## 4. 借阅与归还

### 4.1 借书

`POST /api/loans`

```json
{ "bookId": 1, "readerId": 1 }
```

- **数据归属**：READER 的 `readerId` 必须为自身（替他人借 → `40300`），ADMIN 可代办。
- 校验顺序（失败即短路）：读者冻结 `40905` → 未缴清罚款 `40914` → 超出借阅上限 `40913`（`book.loan.max-borrowing`，默认 5）→ 可借数量不足 `40906`。
- **预约履约**：若该读者持有该书未过期的 `READY` 预约，直接借出并将预约置 `FULFILLED`（名额已预留，不再扣库存）；履约借出同样受上限/罚款/冻结校验。
- 响应 `data` 为借阅记录（`status=BORROWED`，`dueAt = borrowedAt + 30 天`）。

### 4.2 还书

`POST /api/loans/{id}/return`

```json
{
  "code": 0, "message": "ok",
  "data": {
    "id": 5, "bookId": 1, "readerId": 1,
    "borrowedAt": "2026-09-01T10:00:00", "dueAt": "2026-10-01T10:00:00",
    "returnedAt": "2026-10-19T15:30:00.456",
    "overdueDays": 6, "fineCents": 250, "fine": 2.50
  }
}
```

- **数据归属**：READER 只能归还自己的借阅单（还他人 → `40300`）。
- 重复归还 → `40907`。
- 归还同时回补库存；若预约队列非空，队首 `WAITING` 变 `READY`（保留 48 小时，`book.reservation.hold-hours`），该册书被队首预留。
- **逾期自动冻结（第二版）**：`overdueDays > 0` 时读者自动置 `FROZEN`，解冻见 4.4。

### 4.3 借阅记录查询

`GET /api/loans?readerId=&status=&overdue=`

- **数据归属**：READER 查询强制过滤为自己（不传 `readerId` 也只返回自己的；显式传他人 → `40300`）；ADMIN 可按任意 `readerId` 过滤或不传看全部。
- 三个过滤条件均可选；`overdue=true` 表示「在借且已逾期」（按 `dueAt` 实时派生，此时忽略 `status`）。
- `data` 为数组，元素含 `bookTitle`、`readerName`、`overdue` 派生字段与 `fineStatus`（第二版新增）。

### 4.4 缴纳罚款（ADMIN，第二版）

`POST /api/loans/{id}/fine/pay`

```json
{
  "code": 0, "message": "ok",
  "data": { "id": 5, "fineCents": 250, "fine": 2.50, "fineStatus": "PAID", "...": "..." }
}
```

- 仅 `fineStatus = UNPAID` 的借阅可缴纳（否则 `40917`）；不存在 → `40403`。
- 缴纳后若读者处于冻结且**无待缴罚款、无逾期在借**，自动解冻（`ACTIVE`）。
- 罚款禁借口径：读者存在任一 `UNPAID` 借阅即禁止借书与预约（`40914`），与读者是否冻结无关。

## 5. 预约

### 5.1 发起预约

`POST /api/reservations`

```json
{ "bookId": 1, "readerId": 2 }
```

- **数据归属**：READER 的 `readerId` 必须为自身（替他人预约 → `40300`）。
- 校验顺序：未缴清罚款 `40914` → 可借数量非 0 `40908` → 重复活跃预约 `40909`。
- 预约**不校验**借阅上限（排队无害，取书履约时再拦）。
- 新预约进入 `WAITING`，按预约时间 FIFO 排队。

### 5.2 取消预约

`DELETE /api/reservations/{id}`

- **数据归属**：READER 只能取消自己的预约（取消他人 → `40300`）。
- `WAITING` 直接取消；`READY` 取消后名额自动顺延给下一位 `WAITING`，队列已空则归还库存。
- 终态（FULFILLED/CANCELLED/EXPIRED）不可取消 → `40910`。

### 5.3 队列查询

见 2.6。状态机：`WAITING → READY → FULFILLED`，旁路 `CANCELLED`（主动取消）、`EXPIRED`（超过保留期未取，惰性清理顺延）。

## 6. curl 冒烟链路（一条龙）

```bash
BASE=http://localhost:8080

# 1. 登录
TOKEN=$(curl -s -X POST $BASE/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"admin123"}' | sed 's/.*"token":"\([^"]*\)".*/\1/')
AUTH="Authorization: Bearer $TOKEN"

# 2. 建书 + 建读者
BOOK=$(curl -s -X POST $BASE/api/books -H "$AUTH" -H 'Content-Type: application/json' \
  -d '{"isbn":"978-7-111-99999-9","title":"冒烟测试书","totalCopies":1,"priceCents":1000}')
BID=$(echo $BOOK | sed 's/.*"id":\([0-9]*\).*/\1/')
RID=$(curl -s -X POST $BASE/api/readers -H "$AUTH" -H 'Content-Type: application/json' \
  -d '{"name":"冒烟读者","phone":"13999999999"}' | sed 's/.*"id":\([0-9]*\).*/\1/')

# 3. 甲借走最后一本（库存归零）
LOAN=$(curl -s -X POST $BASE/api/loans -H "$AUTH" -H 'Content-Type: application/json' \
  -d "{\"bookId\":$BID,\"readerId\":$RID}")

# 4. 乙预约（此时库存 0，允许）
curl -s -X POST $BASE/api/reservations -H "$AUTH" -H 'Content-Type: application/json' \
  -d "{\"bookId\":$BID,\"readerId\":$RID}"

# 5. 甲归还 → 乙变 READY
curl -s -X POST $BASE/api/loans/$LOAN/return -H "$AUTH"

# 6. 查看队列（READY）与图书状态
curl -s "$BASE/api/books/$BID/reservations" -H "$AUTH"
curl -s "$BASE/api/books/$BID" -H "$AUTH"

# 7. 逾期演示：直接把 due_at 改到过去后归还，返回罚款（维护场景可用 SQL）
```

## 7. 错误码表

| code | HTTP | 含义 |
|---|---|---|
| 40001 | 400 | 参数校验失败（data 为字段级明细） |
| 40002 | 400 | 原密码错误（第二版） |
| 40100 | 401 | 未登录或凭证无效 |
| 40101 | 401 | 用户名或密码错误 |
| 40300 | 403 | 权限不足（非 ADMIN 调管理接口，或 READER 操作他人资源） |
| 40400 | 404 | 资源不存在（路径级） |
| 40401 | 404 | 图书不存在 |
| 40402 | 404 | 读者不存在 |
| 40403 | 404 | 借阅记录不存在 |
| 40404 | 404 | 预约不存在 |
| 40901 | 409 | 书号已存在 |
| 40902 | 409 | 图书存在未归还借阅，无法删除 |
| 40903 | 409 | 图书存在活跃预约，无法删除 |
| 40904 | 409 | 手机号已存在 |
| 40905 | 409 | 读者已被冻结，无法借书 |
| 40906 | 409 | 可借数量不足 |
| 40907 | 409 | 该借阅已归还 |
| 40908 | 409 | 当前有可借数量，无需预约 |
| 40909 | 409 | 已有该书活跃预约，请勿重复预约 |
| 40910 | 409 | 该预约状态不允许取消 |
| 40911 | 409 | 账号已被禁用 |
| 40912 | 409 | 图书信息已被其他操作修改，请重试 |
| 40913 | 409 | 超出借阅上限（第二版） |
| 40914 | 409 | 存在未缴清罚款，禁止借阅与预约（第二版） |
| 40915 | 409 | 用户名已存在（第二版） |
| 40916 | 409 | 总册数不能低于在借与预留之和（第二版） |
| 40917 | 409 | 该借阅无待缴罚款（第二版） |
| 50001 | 500 | 库存状态异常（防御性，出现即说明数据被绕过接口修改） |
| 50000 | 500 | 系统内部错误 |

## 8. 运行说明

```bash
# 1. 起数据库（本机 3306 被原生 mysqld 占用，宿主机映射 3307）
docker compose up -d

# 2. 启动应用（JWT_SECRET 必填，缺失启动失败；ADMIN_PASSWORD 可选）
JWT_SECRET='<至少 32 字节随机串>' ADMIN_PASSWORD='你的口令' \
  ./mvnw spring-boot:run -Dspring-boot.run.jvmArguments="-Dserver.port=8080"
# 或打包运行：./mvnw -o -DskipTests package && JWT_SECRET=... "$JAVA_HOME/bin/java.exe" -jar target/SpringBook-0.0.1-SNAPSHOT.jar

# 3. 健康检查
curl http://localhost:8080/actuator/health
```
