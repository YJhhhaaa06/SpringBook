# SpringBook 图书管理系统

Spring Boot 4 + MyBatis + MySQL 的图书借阅管理系统，含读者端与管理员端。
首次启动会自动建库建表，并灌入一批演示数据，不需要手工导入 SQL。

## 先看这里：三种运行方式

按省事程度排序，选一种即可，**不要混用**。

| 方式 | 需要装 | 适合谁 | 详细步骤 |
|---|---|---|---|
| ① 直接运行 jar | JDK 21+、MySQL 8.0+ | 只想把系统跑起来看效果 | [快速开始](.docs/01-快速开始.md) |
| ② 从源码构建 | JDK 21+、MySQL 8.0+、网络 | 想检查或修改代码 | [从源码构建](.docs/02-从源码构建.md) |
| ③ Docker 一把梭 | Docker | 不想在本机装 JDK 和 MySQL | [用 Docker 运行](.docs/03-用Docker运行.md) |

> 方式 ② 并不会改变数据库驱动的版本，仍然要求 MySQL 8.0+。如果你的数据库是 5.7，重建源码也解决不了问题，请先看下面的版本要求。

## 最快路径（方式 ①）

1. 确认 Java 版本不低于 21：

   ```bash
   java -version
   ```

2. 打开 `application.properties`，只改这三行：数据库账号、密码、端口。

3. 双击 `启动.bat`（Linux / macOS 执行 `sh 启动.sh`）。

4. 浏览器打开 <http://localhost:8080/>。

数据库不需要提前建库建表：连接串带了 `createDatabaseIfNotExist=true`，Flyway 会在首次启动时建表并灌入演示数据。

## 前置条件

| 组件 | 要求 | 说明 |
|---|---|---|
| JDK | **21 或更高** | 字节码目标是 21，低于此版本会报 `UnsupportedClassVersionError` |
| MySQL | **8.0 或更高，推荐 8.4** | 建表用了 MySQL 8 专有的 `utf8mb4_0900_ai_ci` 排序规则 |
| Docker | 可选 | 只有方式 ③ 需要 |

> ⚠️ **MySQL 5.7 和 MariaDB 都不受支持。** 5.7 的驱动支持已被移除，MariaDB 没有 `utf8mb4_0900_ai_ci` 这个排序规则，建表会直接失败。
> 自检命令：`SELECT VERSION();`，返回 `8.0.x` 或 `8.4.x` 才可以用。

手边只有 5.7 也没关系：装一个 MySQL 8.4，把端口错开（比如 3307），在 `application.properties` 里改端口即可，两个版本可以共存。

## 默认账号

| 角色 | 账号 | 口令 | 说明 |
|---|---|---|---|
| 管理员 | `admin` | `admin123` | 首次启动自动创建 |
| 读者 | `及时雨` | `123456` | 演示数据自带，共 25 个好汉账号 |

读者账号的登录名是水浒绰号，例如 `玉麒麟`、`智多星`、`豹子头`。完整名单见[数据库与种子数据](.docs/04-数据库与种子数据.md)。
